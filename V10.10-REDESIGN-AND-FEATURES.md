# Chapter One V10.10 — New Editorial UI + Library Recovery

## Design baseline
Use `assets/chapter-one-ui-reference.jpg` as the exact visual reference and `assets/chapter-one-logo.png` as the app mark. This release removes the V10.9 green/sage and textual wordmark design. The intended UI is warm off-white paper, black editorial typography and a floating black bottom navigation pill. Do not draw iOS/Android status bars, Dynamic Island, carrier/wifi/battery icons or gesture bars; those belong to the device OS.

## Navigation
Four bottom destinations only: Home, Library (file/folder), Profile and Settings. Create and import entry points are surfaced within Home/Library, not extra bottom-nav icons.

## Import flows
The Import Book page offers Direct Import (searchable PDF is saved as a book and appears in Library) and Import & Translate (PDF/DOCX/TXT/MD goes to existing translator workflow). Scanned image-only PDFs require OCR and must show a clear notice.

## New features
- Profile → Recently Deleted: soft-delete books, restore, or permanently delete.
- Settings → daily reading reminder with enable/disable and daily time. Top bell toggles the same preference.
- Reminder uses browser Notification permission while the app is open; it must not claim background delivery when the browser is closed without a push service.
- New uploaded logo appears in splash, Sign In/Sign Up, Home, Library and Profile.

## Preserve
Existing Supabase authentication, private user book sync, local storage, AI provider routing, book creation, translator, reader, audio, ratings, PDF.js/Mammoth imports and environment variable names. Never expose provider secrets in frontend files.
