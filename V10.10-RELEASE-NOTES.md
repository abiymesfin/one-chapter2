# Chapter One V10.10 — New Editorial Design & Library Tools

## Visual update
- Replaced the visible V10.9 visual system with the user-provided cream-paper / black editorial design reference.
- Added the owner-supplied Chapter One mark to splash, sign-in/up, home, library and main pages.
- Removed textual `chapter one.` wordmark from primary header.
- Rebuilt primary bottom navigation to four icon-only destinations in requested order: Home, Library/File, Settings, Profile.
- No simulated status bar, Dynamic Island, carrier, battery, charging, wifi or gesture UI.

## Import
- Added a dedicated Import Book page with Direct Import and Import & Translate options.
- Direct Import opens the PDF selector, extracts selectable text/first-page cover and creates an ordinary library book without requiring AI generation fields.
- Import & Translate reuses the Translator's PDF/DOCX/TXT/MD flow.
- Scanned PDF limitation remains clearly stated; OCR is not falsely claimed.

## Profile / Settings
- Book deletion moves items to Profile → Recently Deleted.
- Restore and permanent-delete actions are available.
- Soft-deleted IDs are excluded from Supabase cloud merge; matching cloud row is removed. Restore upserts the book again.
- JSON backup contains Recently Deleted entries.
- Settings includes daily reminder toggle/time and saved default reader appearance.
- The header bell toggles the reminder state.
- Reminder is browser-local and checks while the app is open / regains focus. It does not promise background delivery while Chrome is fully closed.

## Preserved systems
- Existing Supabase Auth, URL/publishable key and user_books schema.
- Existing AI provider routing and free Amharic quota stop rules.
- Existing AI book creation, story idea, chapter workflow, cover Canvas options, translator, reader, audio and PWA files.
