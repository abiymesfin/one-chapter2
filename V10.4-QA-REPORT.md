# Chapter One V10.4 QA Report

Date: 2026-11-06

## Included changes

- OpenAI text-generation 429 responses now show billing/quota or rate-limit guidance.
- The returned message includes Google's retry delay when present and points to the exact project's Usage & Rate limits dashboard.
- The Netlify function logs only safe diagnostic fields (status, model, quota id/metric and retry delay); it does not log API keys or request prompts.
- 429 responses are not blindly retried because some are daily/project quota exhaustion and immediate retries cannot restore quota.
- OpenAI now powers book text generation and optional cover generation using `OPENAI_API_KEY`.
- If the OpenAI image key is absent or its provider returns 429, the cover picker shows a distinct explanation and the user can choose the standard cover to save the book.
- Existing app pages, account UI, Supabase settings, local/cloud book structure and reader features are unchanged.

## Not live-verified

- Live OpenAI book outline/chapter generation requires a valid OpenAI API key, enabled model access, and available API billing/usage.

- Live Netlify deployment and live provider requests were not tested from this environment.


## Provider migration note
- Book generation and translation use OpenAI Chat Completions at `https://api.openai.com/v1/chat/completions`.
- Default text model: `gpt-6-luna` (overridable with `OPENAI_TEXT_MODEL`).
- One `OPENAI_API_KEY` is used for text and optional image generation.
- Live API calls were not performed during this local QA.
