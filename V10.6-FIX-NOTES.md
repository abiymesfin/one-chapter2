# Chapter One V10.6 — Full Book + Cover Thumbnail Fix

## Fixed
- Create a Book and Story / Movie Idea now save the outline first, then automatically write every chapter in sequence. If a request fails, the outline and all completed chapters remain saved; the user can press **Write remaining** to resume. Cover selection is offered again after a resumed book finishes.
- Chapter generation targets the requested reader-page count using 180 words per reader page, splits long chapters into smaller sections, and adds a continuation pass when a chapter draft is substantially short.
- Reader pagination now uses the same 180-word target as the book generator.
- Four AI cover choices are generated as 640 × 960 JPEG thumbnails with lower response size, reducing the chance of Netlify's buffered function response limit being reached.
- Cover errors now distinguish API key, image-model access/verification, quota, and incomplete-image responses. A cover failure does not delete the already-saved book.

## Required Netlify variables
- `OPENAI_API_KEY`
- `OPENAI_TEXT_MODEL` (default remains `gpt-6-luna`)
- `OPENAI_IMAGE_MODEL` (default remains `gpt-image-2.5-flare`)

No new environment variables or database schema changes are required.
