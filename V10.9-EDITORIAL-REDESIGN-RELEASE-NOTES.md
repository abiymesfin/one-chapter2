# Chapter One V10.9 — Editorial Library Redesign

## Design direction
- Reworked the Home/Favorites screen and Library screen around the user-supplied reference: warm cream paper background, black editorial typography, restrained controls, book-cover focus, stacked-book collection artwork, and a black floating pill navigation bar.
- Retained Chapter One branding rather than copying the reference image's unrelated `n.` wordmark.
- Applied the same cream/black visual language to Create, Translator, Story Idea, Book Details, Reader, Audiobook, Statistics, Profile, Sign In, and Sign Up screens.
- Kept book cards data-driven. No sample books, ratings, collection counts, or fake content were added.

## Library and PDF import
- Library organizes real saved books into genre collections (or `My Books` where a genre is not set).
- Each collection expands to show the real books assigned to it.
- Added visible `Import PDF` controls on Home and Library. They open the existing PDF extraction/import flow rather than creating a second importer.
- Imported PDF text continues to use Chapter One's Reader layout and page navigation. This is a reflowed reading edition, not a pixel-identical PDF page viewer.

## Preserved
- Supabase authentication and user book sync code.
- Existing local backup/restore and reading progress data model.
- Existing AI routing and Netlify functions from V10.8.
- Existing Create a Book, Story/Movie Idea, Translator, cover selection, and audiobook functionality.
